# Popovers

[![GitHub Actions](https://github.com/GODY1403/ahj-forms/actions/workflows/pages.yml/badge.svg)](https://github.com/GODY1403/ahj-forms/actions/workflows/pages.yml)

Всплывающая подсказка на чистом JavaScript. Нажатие на кнопку показывает заголовок и текст над ней, повторное нажатие скрывает подсказку.

[Открыть GitHub Pages](https://gody1403.github.io/ahj-forms/)

Нужны Node.js 24.11+ и Yarn 4.18.1 (через Corepack).

```bash
corepack enable
yarn install --immutable
yarn start
```

Проверки: `yarn lint`, `yarn test`. Сборка: `yarn build`.
